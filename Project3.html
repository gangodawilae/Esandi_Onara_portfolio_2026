Python Quiz Game

My interactive Python quiz project

About This Project

My third project is a Python quiz game. It asks shuffled questions, checks answers, gives hints, and shows colourful feedback using ASCII art and ANSI colour codes. I organised the program using functions, lists, loops, and input validation.

Features I Built

  • Shuffled questions using random.shuffle()
  • Hint system for each question
  • Colourful feedback (correct, wrong, hint)
  • Input validation to prevent empty answers
  • Final score summary with personalised messages
  • Replay option to restart the quiz
  • ASCII art ending
