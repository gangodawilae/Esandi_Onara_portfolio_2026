Project Overview

This project is a python menu system that allows user to choose between three options which are, Wordle, Magic 8 Ball, and Pokemon Battle. Each game is stored inside its own function and the main menu calls the correct function based on user's input.

Wordle

A 5 letter gussing game with hints

Magic 8 ball

Ask a question and receive a random fortune.

Pokemon Battle

Choose attacks and defeats a wild pokemon.

Skills I used

  • Python functions and modular programing
  • Lists and dictonaries
  • User input alidation and loops
  • Randomisation with random
  • ASCII art and coloured output
  • Degugging and testing programs

Project Highlights

  • I built a simple menu system that let the user chooose between three different games.
  • I used dictonaries to store each Pokemon's health and the damage of different attacks.
  • I added colourful feedback using ASCII escape codes to make the game more fun.
  • I added input checks so the game doesn't crash when the user types soemthing wrong.
  • I used loops to keep the games running until the user dicides to quit.
